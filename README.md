# Below Threshold

**Factor a number with a quantum computer, then keep it alive.** An interactive guide to Shor's algorithm and the quantum Fourier transform, and to the quantum error correction needed to run them, ending on why real-time decoding is the bottleneck for fault-tolerant quantum computing. By **Team PhASE** for the Quantum Unlocked track.

- **Live demo:** https://bbfutaba.github.io/below-threshold/
- **3-minute pitch video** (narrated by the team, subtitles burned in), in four parts in [`video/`](video/):
  1. [The problem](video/pitch-part-1-problem.mp4) (0:27)
  2. [Learn: from a qubit to Shor's algorithm](video/pitch-part-2-learn.mp4) (0:49)
  3. [Play: error correction and the decoder](video/pitch-part-3-play.mp4) (0:48)
  4. [Prove: the lab, the checks, the close](video/pitch-part-4-prove.mp4) (0:49)

  In one piece and in full quality, with the 15-minute narrated explainer film below it, on the live site's [Film page](https://bbfutaba.github.io/below-threshold/film).

## What you can do

| | |
|---|---|
| **Learn** | Twelve short chapters on an exact state-vector simulator, in three parts. **Part I, Quantum basics:** what a qubit is (superposition, measurement, interference), many qubits at once (2ⁿ amplitudes, product states), and entanglement. **Part II, Shor's algorithm:** factoring as a hunt for a period, phase as a hidden clock, the quantum Fourier transform, Shor's algorithm end to end, and what noise does to it. **Part III, Keeping it alive:** no-cloning, syndrome extraction, phase errors, error discretization. |
| **QFT** | Step through the real gate circuit one gate at a time and watch amplitudes as clocks, each qubit's Bloch arrow and the output peaks. |
| **Shor's** | Factor 15, 21, 33 or 35 in seven steps, then watch noise dissolve the peaks on a 10-qubit gate-level circuit. |
| **Play** | Keep a Shor's algorithm run alive by protecting its logical qubit on a rotated surface code (d = 3, 5, 7). Errors are hidden; only the alarms light up, like real hardware. A guided first level makes it playable with no background, then a real matching decoder solves the same seeded puzzle. |
| **Real-time** | Rounds arrive on a clock and each decoder's speed is measured live in your browser. Slow decoders build a backlog and the computation stalls. |
| **Lab** | Live Monte Carlo: watch curves for different code sizes cross at the threshold. |
| **Film** | The narrated 3-minute pitch and a narrated 15-minute explainer in the style of 3Blue1Brown, every frame drawn from the same simulation code. |

## Is it real?

Yes. Every number in the app is computed live or comes from the validation suite.

- **Shor and the QFT:** the QFT gate circuit equals the exact discrete Fourier transform on random states, and without noise the gate-level Shor circuit reproduces the register-level distribution exactly.
- **Decoding:** our blossom MWPM matches brute force on every instance with up to 16 defects, and PyMatching's correction weight on **100%** of 90,000 exported decoding problems.
- **Code layout:** equal to Stim's rotated surface code for d = 3 to 11.
- **Tests:** 125 unit tests and 66 end-to-end checks.
- **Thresholds** with our own decoders, up to d = 13:

| Noise | Decoder | Ours | Stim / PyMatching reference | Published |
|---|---|---|---|---|
| Bit flip | MWPM | 9.94% | 9.85% | ≈ 10.3% |
| Bit flip | Union-find | 9.59% | | ≈ 9.9% |
| With measurement errors | MWPM | 2.84% | 2.85% | ≈ 2.9% |
| With measurement errors | Union-find | 2.48% | | ≈ 2.6% |
| Depolarizing | MWPM | 14.6% | | ≈ 15.5% |

![Threshold crossing, bit-flip noise](validate/plots/bitflip_mwpm.png)

**What we simplify** (also shown in the app):
- Shor's algorithm on small numbers (15 to 35);
- code-capacity and phenomenological noise, not circuit-level;
- X and Z decoded separately;
- a slowed clock with a labeled hardware speed-up in real-time mode;
- small code distances.

## Run it

Unzip `below-threshold-source.zip`, then from the `below-threshold/` folder (Node 20+):

```bash
npm install
npm run dev            # http://localhost:5173
npm test               # unit and property tests
npm run build && npm run test:e2e   # end-to-end tests (desktop and mobile)
```

Videos are not in the archive, so on a local copy the Film page has no film and the chapter clips are hidden; the live site has them. The validation suite (Python 3.11) is in `validate/`; see the archive's own README for the commands.
